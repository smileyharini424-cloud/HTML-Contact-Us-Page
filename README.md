# HTML Contact Us Page

## Explanation

This project demonstrates how to create a simple Contact Us page using HTML form elements.

## Problem Statement

Create a Contact Us page that collects the user's name, email address, subject, and message.

## Features

* Name input field
* Email input field
* Subject input field
* Message textarea
* Submit button
* Reset button

## How It Works

The `<form>` element creates the contact form.

Text and email input fields collect the user's information.

The subject field allows the user to specify the purpose of the message.

The `<textarea>` element is used to enter a detailed message.

The Submit button submits the form, and the Reset button clears the entered data.

## Technologies Used

* HTML5

## Program Flow

1. Open the Contact Us page.
2. Enter the name.
3. Enter the email address.
4. Enter the subject.
5. Type the message.
6. Click Submit or Reset.

## Sample Input

Name: Harini
Email: [harini@example.com](mailto:harini@example.com)
Subject: Website Feedback
Message: I would like to provide some feedback.

## Sample Output

A Contact Us page is displayed with fields for name, email, subject, message, Submit, and Reset buttons.
